# 🧠 Substrate-Prism Neuron: A New Architecture for Emotional Reasoning in AI

This repository supports the paper **“She Knows He Cheats But…”**, a theoretical framework introducing a new neuron model that allows AI to simulate emotional conflict, compromise, and recursive human-like reasoning.

The **Substrate-Prism Neuron** integrates emotionally valenced inputs (e.g., betrayal, guilt, loyalty) with motivational substrates (e.g., children, shared trauma, values), using recursive mirror logic and median-based activation to reflect how humans reason through dilemmas — especially those involving love, memory, or moral tradeoffs.

> It’s designed not to “solve” but to **simulate**:  
> to hesitate, to loop, to feel stuck — just like we do.
